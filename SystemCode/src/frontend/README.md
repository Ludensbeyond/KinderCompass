# KinderCompass frontend

This folder contains the Next.js interface for the KinderCompass PoC 1
workflow. The UI collects family details and preschool preferences, displays
ranked and costed recommendations, compares selected centres, and plots
home-to-preschool distances on an interactive map.

## Quick start

The recommended Windows workflow starts the frontend and FastAPI backend
together. From the repository root:

```powershell
.\run_poc1.ps1
```

For a first-time setup, install both projects' dependencies before starting:

```powershell
.\run_poc1.ps1 -InstallDependencies
```

The launcher opens each service in a separate PowerShell window and creates
`SystemCode/src/frontend/.env.local` from `.env.local.example` if necessary.
Wait until Next.js reports that it is ready, then open
`http://localhost:3000`. Press `Ctrl+C` in both service windows to stop the
application.

## Manual development setup

Prerequisites:

- Node.js with npm;
- the repository Python environment at `.venv`;
- the backend dependencies and repository-level `.env` described in the
  [PoC 1 guide](../../../docs/poc1/Readme.md).

Install the exact dependency versions recorded in `package-lock.json`:

```powershell
npm ci --prefix SystemCode/src/frontend
```

Create `SystemCode/src/frontend/.env.local` from `.env.local.example`:

```dotenv
NEXT_PUBLIC_API_URL=http://localhost:8000
```

`NEXT_PUBLIC_API_URL` is embedded into the browser bundle. Restart the Next.js
development server after changing it. If the variable is absent, the UI also
defaults to `http://localhost:8000`.

Start the backend from the repository root:

```powershell
.venv\Scripts\python.exe -m uvicorn SystemCode.src.backend.main:app --reload
```

In another terminal, start the frontend:

```powershell
npm --prefix SystemCode/src/frontend run dev
```

The frontend is available at `http://localhost:3000`; FastAPI is available at
`http://127.0.0.1:8000`, with API documentation at
`http://127.0.0.1:8000/docs`. The interface may render without the backend, but
preference updates, recommendations, eligibility checks, and distance
calculations will fail.

## Available commands

Run these from the repository root:

| Command | Purpose |
|---|---|
| `npm --prefix SystemCode/src/frontend run dev` | Start the development server with live reload. |
| `npm --prefix SystemCode/src/frontend run build` | Type-check and create an optimized production build. |
| `npm --prefix SystemCode/src/frontend run start` | Serve an existing production build. |
| `npm --prefix SystemCode/src/frontend run lint` | Run the Next.js lint command; the first run prompts you to create an ESLint configuration. |

Build before using `start`:

```powershell
npm --prefix SystemCode/src/frontend run build
npm --prefix SystemCode/src/frontend run start
```

## Folder contents

| Path | Description |
|---|---|
| `app/page.tsx` | Main client application. Holds the three-stage workflow state, calls FastAPI, manages preferences and selected schools, and renders recommendation, eligibility, cost, distance, and citation details. |
| `app/LiveMap.tsx` | Client-only Leaflet map. Loads Leaflet dynamically, plots home and preschool markers, and draws straight-line comparisons using OpenStreetMap tiles. |
| `app/layout.tsx` | Root App Router layout and page metadata; imports the global stylesheet. |
| `app/globals.css` | Global theme, responsive layout, form, chat, result-card, evidence, and Leaflet styles. It also imports the DM Sans and Fraunces web fonts. |
| `.env.local.example` | Safe template for the public backend base URL. Copy it to `.env.local` for local development. |
| `.env.local` | Local frontend environment values. It is ignored by Git and should not contain server-side secrets. |
| `.gitignore` | Excludes dependencies, Next.js build output, local environment configuration, and TypeScript build metadata. |
| `package.json` | Project metadata, npm commands, and direct runtime/development dependencies. |
| `package-lock.json` | Reproducible dependency lockfile used by `npm ci`. |
| `tsconfig.json` | Strict TypeScript and Next.js compiler configuration. |
| `next-env.d.ts` | Next.js-generated TypeScript declarations. Do not edit this file manually. |
| `node_modules/` | Locally installed packages; generated and ignored by Git. |
| `.next/` | Development and production build output; generated and ignored by Git. |

## Application and API relationship

`app/page.tsx` sends JSON requests to the backend URL configured by
`NEXT_PUBLIC_API_URL`. The interface depends on the backend for:

- accumulating and validating conversational preferences;
- querying and ranking preschool recommendations;
- checking care-level eligibility and estimating monthly fees;
- resolving postal codes and calculating straight-line distances; and
- retrieving grounded school or general-guidance citations.

The frontend does not connect directly to Neo4j, OneMap, OpenAI, or webpage-RAG
resources. Credentials for those services belong in the repository-level
backend `.env`, never in `.env.local` or browser code.

## Troubleshooting

- If the page loads but actions fail, confirm FastAPI is running on port 8000
  and that `NEXT_PUBLIC_API_URL` points to it.
- If a changed API URL has no effect, stop and restart the Next.js server.
- If packages are missing, rerun `npm ci --prefix SystemCode/src/frontend` or
  use `.\run_poc1.ps1 -InstallDependencies`.
- If `npm run lint` opens a setup prompt, select an ESLint configuration first;
  linting is not non-interactive until that configuration has been created.
- If port 3000 or 8000 is already in use, stop the existing frontend or backend
  process before launching another copy.
- If the map background does not load, check network access to OpenStreetMap's
  public tile service; recommendation and distance data can still be returned by
  the backend.

See the [PoC 1 guide](../../../docs/poc1/Readme.md) for the complete system setup,
pipeline behavior, tests, and limitations.
